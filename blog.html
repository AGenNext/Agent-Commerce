Agentic commerce playbook

The road to autonomous commerce starts with agents that can actually transact.

Agent-Commerce is an open-source foundation for AI-powered storefronts, marketplaces, and payment flows. It brings together Universal Commerce Protocol-style agents, A2A transport, a SurrealDB data layer, and payment adapters designed for the next wave of machine-assisted buying and selling.

Why commerce needs agents

Traditional commerce software was built for humans clicking through catalogs, carts, dashboards, and payment forms. The next interface is different: customers delegate intent to assistants, merchants delegate operations to agents, and marketplaces need a shared layer where discovery, checkout, inventory, payouts, and support can be coordinated programmatically.

That shift requires more than a chatbot. A useful commerce agent needs product and order skills, reliable state, payment orchestration, admin controls, marketplace primitives, and enough protocol flexibility to work across platforms.

What Agent-Commerce provides

40+Commerce skills for products, orders, carts, vendors, admin, and payments.
8Adapters covering AP2, x402, Stripe, PayPal, Mastercard, Open Banking, MPP, and Shopify.
1Unified SurrealDB-backed layer for relations, search, live queries, and operational data.

The architecture in plain English

Agent-Commerce is organized around practical modules: a UCP commerce agent for skills and agent cards, a store manager for product and order operations, a marketplace manager for vendors and payouts, a site admin layer for roles and API keys, and payment adapters that make provider switching cleaner.

Customer intent → Commerce agent → Store / marketplace skills
                 ↓
             Payment adapter → Provider checkout or machine payment
                 ↓
             SurrealDB → products, orders, users, logs, relations

Who should use it

Use Agent-Commerce if you are prototyping an AI storefront, experimenting with agentic payments, building a marketplace, or evaluating how autonomous agents could operate safely inside your commerce stack. It is especially useful for teams that want a practical reference implementation instead of a slideware-only architecture.

How to start

git clone https://github.com/AGenNext/Agent-Commerce.git
cd Agent-Commerce
pip install -r requirements.txt
python test_e2e.py
python server.py

Build the first version this week
